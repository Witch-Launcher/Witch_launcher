## What we provide

Witch Launcher is a free, open-source community fork of Amethyst-iOS. It manages Minecraft: Java Edition versions, loaders, Java runtimes and renderers on iOS, and supports signed `.plgw` plugins.

## What we do not provide

- Minecraft: Java Edition game files — you supply your own
- Microsoft/Mojang certificates — you sign and sideload yourself
- Minecraft accounts — use your own
- Uptime guarantees for third-party services (Modrinth, CurseForge, GitHub, Witch registry)

## Your responsibilities

- Own a legitimate copy of Minecraft: Java Edition
- Sign and install the launcher via your chosen method (SideStore, AltStore, TrollStore, jailbreak)
- Keep your certificates, pairing files and signing setup secure
- Review plugin source before installing native plugins (they run unsandboxed)

## Plugin system

Plugins are `.plgw` packages signed with ECDSA P-256. Native plugins run in the launcher process and are not sandboxed — install at your own risk. Registry verification confirms package integrity, not safety.
