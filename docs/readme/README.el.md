<a id="about"></a>
## Περίπου

Η **Witch Launcher** είναι μια ανεξάρτητη, διατηρούμενη από την κοινότητα διχάλα του [Amethyst](https://github.com/AngelAuraMC/Amethyst-iOS) που φέρνει τις **Minecraft: Java Edition** στις iPhone και iPad. Συνδυάζει μια διεπαφή εκκίνησης πρώτης επαφής με μια πλήρη διαχείριση χρόνου εκτέλεσης Java, LWJGL και μια στοίβα γραφικών που είναι χτισμένη γύρω από τα επίπεδα μετάφρασης Metal, MoltenVK και OpenGL.

Η Witch βασίζεται στο έργο των [Boardwalk](https://github.com/zhuowei/Boardwalk), της κοινότητας [PojavLauncher](https://github.com/PojavLauncherTeam), Amethyst-iOS και Amethyst-iOS-25. Είναι ένα ανεξάρτητο έργο και δεν συνδέεται με την ομάδα Mojang Studios, Microsoft, ή την ανοδική ομάδα Amethyst.

> **Τρέχουσα έκδοση:** 0.0.4 · Δείτε [`news.md`](../../news.md) για σημειώσεις έκδοσης.

## Χαρακτηριστικά

### Minecraft και mods

- Εκτελεί τις περισσότερες εκδόσεις **Minecraft: Java Edition**, από τις πρώτες εκδόσεις Beta έως τα πιο πρόσφατα στιγμιότυπα.
- Υποστηρίζει **Βανίλια, Fabric, Quilt, Forge, NeoForge και OptiFine**.
- Δημιουργήστε μεμονωμένα **προφίλ παιχνιδιών** με τις δικές τους ρυθμίσεις, mods, shaders, πακέτα πόρων και κόσμους.
- Περιηγηθείτε και εγκαταστήστε περιεχόμενο από τις **Modrinth και CurseForge** χωρίς να φύγετε από το πρόγραμμα εκκίνησης:
  - mods
  - modpacks
  - πακέτα shader
  - πακέτα πόρων
  - χάρτες περιπέτειας και κόσμους
- Επίλυση και εγκατάσταση εξαρτήσεων mod όπου τις παρέχει η πηγή.
- Εισαγάγετε JAR του προγράμματος εγκατάστασης Forge/NeoForge και εγκαταστήστε τους φορτωτές Fabric/Quilt απευθείας από τον επιλογέα έκδοσης.

### Γραφικά και απόδοση

- Εναλλαγή μεταξύ πολλών προγραμμάτων απόδοσης από **Ρυθμίσεις → Renderer & Display**:
  - **gl4es** — OpenGL 2.1 διαδρομή συμβατότητας
  - **ANGLE** — OpenGL ES έως Metal ή Vulkan
  - **MobileGlues** — OpenGL 4.0, Minecraft 1.17+, πειραματικό
  - **Zink** — OpenGL 4.1 έως Mesa 25 και MoltenVK
  - **LTW** — OpenGL 3.3 έως OpenGL ES/Metal, Minecraft 1.17+, πειραματικό
  - **TGLMT** — OpenGL 4.6 Βασική έως Metal, A11 Bionic ή νεότερη
- **TGLMT με υποστήριξη Sodium και Iris** για σύγχρονες ρυθμίσεις που βασίζονται σε shader.
- **Δημιουργία καρέ** με προσαρμοστική GPU κίνησης (MADI) και λειτουργίες επανέκδοσης 3D κάμερας, συμπεριλαμβανομένης της χρονικής παρεμβολής και της προγνωστικής παρέκτασης.
- Κλιμάκωση ανάλυσης, μέγιστος ρυθμός καρέ, αναβάθμιση FSR 1.0, κρυφές μνήμες shader GLSL και συντονισμός ανά απόδοση απόδοσης.
- HUD απόδοσης με ρυθμιζόμενα γραφικά στοιχεία FPS, CPU, GPU, RAM, θερμοκρασία, μπαταρία, ρολόι και καρέ FPS.
- Ενσωματωμένη εγγραφή απόδοσης με γραφήματα, εξαγωγή PNG/PDF και κοινή χρήση.

### Έλεγχοι

- Πλήρως προσαρμόσιμες διατάξεις ελέγχου επί της οθόνης, μεγέθη κουμπιών και διαφάνεια.
- Υποστήριξη **Πληκτρολόγιο και ποντίκι**, συμπεριλαμβανομένου ενός εικονικού ποντικιού και ρυθμιζόμενης ταχύτητας δείκτη.
- Υποστήριξη **χειριστήριο παιχνιδιών** με διαμορφώσιμες διατάξεις και ευαισθησία.
- **Γυροσκόπιο** που στοχεύει με ρυθμιζόμενη ευαισθησία και αναστροφή άξονα.
- Χειρονομίες ποντικιού, κύλισης και hotbar.
- Προαιρετική συμπεριφορά: πατήστε για να τοποθετήσετε μπλοκ, κρατήστε πατημένο για να σπάσετε μπλοκ.
- Πατήστε δύο φορές τη γραμμή πρόσβασης για να ανταλλάξετε το στοιχείο που κρατάτε σε ακατάλληλο.
- Συρόμενη μπάρα εστίας και ρυθμιζόμενος χρονισμός με παρατεταμένο πάτημα.

### Εκκίνηση και λογαριασμοί

- Υποστήριξη λογαριασμού **Microsoft**, **τοπικό/εκτός σύνδεσης**, **επίδειξης** και **Ely.by**.
- Διαχειριστείτε τους χρόνους εκτέλεσης **Java 8, 17, 21 και 25**, πραγματοποιήστε λήψη τους εντός εφαρμογής ή εισαγάγετε τους δικούς σας.
- Επιλέξτε εκδόσεις LWJGL και συντονίστε ορίσματα JVM, μεταβλητές περιβάλλοντος και εκχώρηση μνήμης.
- Αυτόματη διαχείριση RAM για συσκευές με περιορισμένη μνήμη.
- Θέματα, χρώματα έμφασης, θάμπωμα, περιγράμματα, ακτίνα γωνίας, προσαρμοσμένες γραμματοσειρές εκκίνησης και εικονίδια εφαρμογών.
- Εντός παιχνιδιού **F3 πληροφορίες συσκευής**: τσιπ συσκευής, έκδοση iOS, όνομα/έκδοση εκκίνησης, αριθμός έκδοσης και τύπος κατασκευής.
- Προαιρετικές ενσωματώσεις **Witch Διακομιστής**, CurseForge και AI για σύνθετες ρυθμίσεις.
- **52 γλώσσες εντός εφαρμογής**, συμπεριλαμβανομένων πακέτων γλωσσών από δεξιά προς τα αριστερά και διασκεδαστικές τοπικές ρυθμίσεις.

<a id="requirements"></a>
## Απαιτήσεις

| Απαίτηση | Λεπτομέρειες |
|---|---|
| **Συσκευή** | iPhone ή iPad με επεξεργαστή arm64 και υποστήριξη Metal |
| **Σύστημα** | iOS ή iPadOS **14.0 ή νεότερη** |
| **JIT** | Υποχρεούμαι. Ενεργοποίηση JIT μέσω των StikDebug, SideStore, TrollStore ή εγκατάστασης με jailbroken |
| **Λογαριασμός** | Ένας λογαριασμός Microsoft στον οποίο ανήκει η Minecraft για επίσημες λήψεις. τοπικές λειτουργίες και λειτουργίες επίδειξης είναι επίσης διαθέσιμες |
| **Αποθήκευση** | Χώρος για το πρόγραμμα εκκίνησης, Java χρόνους εκτέλεσης, εκδόσεις παιχνιδιών, mods και κόσμους |
| **Δίκτυο** | Απαιτείται για είσοδο, λήψεις έκδοσης, πρόγραμμα περιήγησης περιεχομένου και προαιρετικές διαδικτυακές υπηρεσίες |

Η Witch **δεν** περιλαμβάνει Minecraft αρχεία παιχνιδιού. Τα αρχεία παιχνιδιών λαμβάνονται μέσω του προγράμματος εκκίνησης αφού συνδεθείτε σε έναν κατάλληλο λογαριασμό.

### JIT σημειώσεις

Το Minecraft: Java Edition χρειάζεται JIT και το Witch δεν μπορεί να ξεκινήσει το παιχνίδι χωρίς αυτό.

- **SideStore / AltStore εγκαταστάσεις τύπου:** ενεργοποιήστε την JIT για την Witch και διατηρήστε την απαιτούμενη σύνδεση VPN/εντοπιστή σφαλμάτων ενεργή. Το μήνυμα εντός εφαρμογής αναφέρεται στις **LocalDevVPN** και `CS_DEBUGGED`.
- **StikDebug:** επισυνάψτε την StikDebug στην Witch και ενεργοποιήστε την JIT. Στις **iOS 26/27**, η StikDebug πρέπει να παραμείνει συνδεδεμένη κατά τη διάρκεια του παιχνιδιού. Η `UniversalJIT26.js` αντιγράφεται στο πρόχειρο όταν χρειάζεται.
- **TrollStore:** ενεργοποιήστε την **URL Scheme** στην TrollStore εάν η Witch συνεχίσει να περιμένει την JIT.
- **Συσκευές jailbroken:** χρησιμοποιήστε τον ενεργοποιητή JIT που προτιμάτε.
- Εάν ο εκκινητής παραμένει στην οθόνη **Αναμονή για JIT**, ελέγξτε τη σύνδεση του προγράμματος εντοπισμού σφαλμάτων, τη ρύθμιση VPN και TrollStore URL Scheme πριν από την επανεκκίνηση.

Η συμπεριφορά της JIT εξαρτάται από την έκδοση iOS και τη μέθοδο εγκατάστασης. Οι ενημερώσεις συστήματος μπορεί να διακόψουν τις υπάρχουσες ρυθμίσεις JIT.

<a id="installation"></a>
## Εγκατάσταση

Η Witch πρέπει να είναι υπογεγραμμένη για τη συσκευή σας. Αυτό το αποθετήριο δεν αποστέλλει πιστοποιητικά ή προϋπογεγραμμένες IPA.

### Χρησιμοποιήστε μια κατασκευή

1. Κάντε λήψη μιας έκδοσης ανάπτυξης από τη [ροή εργασιών ανάπτυξης](https://github.com/Witch-Launcher/Witch_launcher/actions/workflows/development.yml) ή χρησιμοποιήστε μια υπογεγραμμένη έκδοση από μια πηγή που εμπιστεύεστε.
2. Υπογράψτε και εγκαταστήστε το με τα **SideStore**, **AltStore**, **TrollStore** ή τη μέθοδο πλευρικής φόρτωσης που προτιμάτε.
3. Ενεργοποιήστε την JIT όπως περιγράφεται παραπάνω πριν ξεκινήσετε το παιχνίδι.

Το TrollStore build χρησιμοποιεί πρόσθετα δικαιώματα και δεν θα πρέπει να εγκατασταθεί με κανονικό signer sideloading.

### Κατασκευή από την πηγή

Η μεταγλώττιση της Witch απαιτεί macOS με εργαλεία γραμμής εντολών Xcode, μια iOS SDK 14.0 ή νεότερη, CMake, JDK 8, `ldid`, `wget`, `zip` και Git.

```bash
git κλώνος --αναδρομικός https://github.com/Witch-Launcher/Witch_launcher.git
cd Witch_launcher
make jre-download
make -j"$(sysctl -n hw.ncpu)" package
```

Οι συσκευασμένες εκδόσεις εγγράφονται στην `artifacts/`.

Για να δημιουργήσετε ένα πακέτο TrollStore αντ' αυτού:

```bash
make package TROLLSTORE_JIT_ENT=1
```

Για συνδέσμους πηγής απόδοσης και σημειώσεις κατασκευής, δείτε [`note.md`](../../note.md).

<a id="notes-and-limitations"></a>
## Σημειώσεις και περιορισμοί

- **JIT είναι υποχρεωτική.** Χωρίς μια λειτουργική ρύθμιση JIT, η Minecraft δεν θα ξεκινήσει.
- **iOS 26/27 JIT είναι εύθραυστη.** Η StikDebug πρέπει να παραμείνει συνδεδεμένη και οι μελλοντικές ενημερώσεις λειτουργικού συστήματος ενδέχεται να αλλάξουν αυτό που λειτουργεί.
- Τα προγράμματα απόδοσης με την ένδειξη **πειραματική** μπορεί να διακοπούν ή να αποδοθούν εσφαλμένα. Ξεκινήστε με **Auto** εάν δεν είστε σίγουροι.
- Η **Γενιά πλαισίων** απαιτεί την απόδοση απόδοσης MoltenVK και την υπολογιστική υποστήριξη Metal. Μπορεί να αυξήσει τη χρήση της μπαταρίας και τη θερμοκρασία της συσκευής.
- Ορισμένα mod, modpacks, shaders και κόσμοι ενδέχεται να απαιτούν μια συγκεκριμένη έκδοση Minecraft, πρόγραμμα φόρτωσης, απόδοσης ή πρόσθετη μνήμη.
- Τα modpacks CurseForge χρησιμοποιούν `manifest.json`. εάν η εγκατάσταση με ένα πάτημα δεν είναι διαθέσιμη για ένα πακέτο, εισαγάγετε το αρχείο με μη αυτόματο τρόπο.
- Οι διαδικτυακές λειτουργίες εξαρτώνται από υπηρεσίες τρίτων και ενδέχεται να μην είναι διαθέσιμες.
- Τα στιγμιότυπα οθόνης προέρχονται από μια έκδοση ανάπτυξης και ενδέχεται να μην αντιστοιχούν ακριβώς στην τρέχουσα έκδοση.
