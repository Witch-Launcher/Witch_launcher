# Welcome to Witch launcher for iOS
[![Development Build](https://img.shields.io/github/actions/workflow/status/Witch-Launcher/Witch_launcher/development.yml?branch=beta&style=for-the-badge)](https://github.com/Witch-Launcher/Witch_launcher/actions/workflows/development.yml)

This repository contains the code for our iOS and iPadOS port of Amethyst. Looking for [Android?](https://github.com/AngelAuraMC/Amethyst-Android)

Witch Launcher is an iOS and iPadOS port of **Amethyst**, bringing Minecraft: Java Edition to Apple mobile devices.

---

## About

Amethyst is a Minecraft: Java Edition launcher originally based on [Boardwalk](https://github.com/zhuowei/Boardwalk) and [Amethyst-iOS](https://github.com/AngelAuraMC/Amethyst-iOS).

Witch Launcher continues this work with additional improvements and optimizations for modern iOS and iPadOS devices.

### Features

* Supports most versions of **Minecraft: Java Edition**, from early Beta releases to the latest snapshots.
* Supports **Forge, NeoForge, Fabric, OptiFine, and Quilt**.
* Customizable on-screen controls.
* Keyboard and mouse support.
* Game controller support.
* Optimizations for **jailbroken and TrollStore devices**.
* Microsoft account authentication.
* Minecraft demo mode support.
* Vulkan-based rendering through **MoltenVK / MetalVK-compatible rendering paths**.
* And more.
